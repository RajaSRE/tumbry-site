# Tumbry site

Public pages for **Tumbry**, a cosmic merge puzzle for iPhone.

- `index.html`: landing page (App Store badge, screenshots, FAQ, support and privacy links)
- `press.html`: press kit (fact sheet, descriptions, full-size screenshots in `press/`, icon, banner)
- `privacy.html`: privacy policy
- `support.html`: support / FAQ
- `img/`: page images, `og.jpg` is the 1200×630 social preview

Served via GitHub Pages. Tumbry collects no personal data.
